# Site Structure and Interactions

## Recommended navigation

Keep the existing set of focused pages, in this order:

1. Home
2. Projects
3. Experience
4. About
5. Toolkit (the existing Skills page)
6. Contact

Projects and Experience should be easy to reach from every page. Home should feature MorningTide and link directly to the project details. Avoid adding a separate page or tab for every active study; surface those projects in the portfolio with clear status labels.

## Useful interactions

- Filter projects by both field and status, with visible active states and a result count.
- Use only the supplied MorningTide demo video on Home and Projects, with native playback controls. Do not use the former AI-generated illustration as an image or video poster.
- Use expandable, keyboard-operable project details for architecture or research methods.
- Provide a copy-email button with success and failure feedback; keep the regular email link as a fallback.
- Retain the interactive skills map if it remains usable on mobile and keyboard/screen-reader alternatives are provided.
- Add a downloadable resume only after a real resume asset is supplied and verified. Do not create a broken placeholder link.
- Keep motion subtle and support `prefers-reduced-motion`.

All controls should be keyboard reachable, have descriptive accessible names, and expose state where relevant. Do not hide essential project facts inside an interaction.
